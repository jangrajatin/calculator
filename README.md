# Simple Python Calculator

A beginner-friendly calculator made with Python that performs basic arithmetic operations like addition, subtraction, multiplication, and division.
This project is great for learning:

* User input in Python
* Conditional statements (`if-elif-else`)
* Basic operators
* Simple program flow

## Features

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`X` or `x`)
* Division (`/`)
* Easy-to-understand code structure

## Technologies Used

* Python 3

## How to Run

1. Install Python on your system
2. Save the file as `calculator.py`
3. Run the program:

```bash
python calculator.py
```

## Example

```text
Enter your 1st value:
10

Enter your 2nd value:
5

+ , -, X , /
:
+

Output:
15
```
